## opencode
- **카탈로그**: `packages/core/src/models-dev.ts` — 소스 `Flag.OPENCODE_MODELS_URL || "https://models.opencode.ai"`, 디스크 TTL 5분, 백그라운드 60분 갱신, Flock 프로세스 락, `OPENCODE_MODELS_DEV` 빌드타임 스냅샷. 스키마는 `packages/core/src/v1/config/provider.ts`(`limit.context/input/output`, `cost`에 `context_over_200k` 가격 티어, `variants`, `reasoning_options`, `options.setCacheKey`). 하드코딩 커스텀 로더 23개는 `packages/opencode/src/provider/provider.ts`(`custom()`), 테스트 fixture `test/tool/fixtures/models-api.json`에 **159 provider**. 일일 cron `.github/workflows/models-snapshot.yml`이 스냅샷을 `v2`에 커밋(`dev`에는 없음). `packages/llm/DESIGN.md` L636: "Normal execution performs no catalog network requests."
- **fallback**: `packages/opencode/src/session/retry.ts` — `RETRY_MAX_RETRIES=5`, base 2000ms × factor 2, jitter 0.25, 헤더 없을 때 cap 30s, `retry-after`(초 또는 HTTP-date) 우선, 7개 재시도 패턴. 컨텍스트 오버플로우는 명시적으로 재시도 안 함. **모델 폴백 체인 없음.**
- **effort**: `packages/opencode/src/provider/transform.ts` — `WIDELY_SUPPORTED_EFFORTS=["low","medium","high"]` + OpenAI 전용 `none`/`xhigh`(출시일 게이트 `2025-11-13`/`2025-12-04`). `variants()`가 패밀리별 wire 변환(Gemini `thinkingConfig.thinkingLevel`, GLM-5.2 effort↔max, Kimi adaptive, MiniMax `chat_template_kwargs`), 10개 패밀리는 명시적으로 variant 비활성.
- **컨텍스트**: `session/overflow.ts` `COMPACTION_BUFFER=20_000`, `session/compaction.ts` 보존 테일 = usable의 25%(2k~15k 클램프). 200k/1M 하드코딩 테이블 없음(모두 `model.limit`에서).
- **cache**: `packages/llm/src/cache-policy.ts` — `AUTO = {tools, system, messages:"latest-user-message"}`(gap-filling만, 수동 힌트 보존, no-op 아이덴티티 검사), `RESPECTS_INLINE_HINTS`로 OpenAI/Gemini는 스킵. `protocols/anthropic-messages.ts` `ANTHROPIC_BREAKPOINT_CAP=4`(초과 시 400 → 드롭), 5m/1h TTL. 구형 `transform.ts` `applyCaching()`은 시스템 앞 2 + 마지막 2 메시지에 프로바이더별 키 표기(`cacheControl`/`cache_control`/`copilot_cache_control`/`cachePoint`).
- **프로토콜**: `packages/llm/src/protocols/index.ts` 6개 어댑터. provider.ts에 하드코딩된 선택(openai/xai/meta → responses, copilot은 `gpt-(\d+)>=5` 정규식으로 arbitration).
- **UX**: TUI `/models` (alias `/mo`) + fuzzysort 피커(`tui/src/component/dialog-model.tsx`), CLI `models --refresh`. 에이전트 frontmatter `provider`+`model` → `provider/model` 문자열(`config/config.ts` L281).

## oh-my-openagent (OmO)
- **카탈로그**: `packages/model-core/src/model-capabilities-snapshot.ts`가 models.dev를 **소문자 bare 모델 ID 맵으로 평탄화**(`models[id.toLowerCase()]`). 번들 스냅숏 `packages/omo-opencode/src/generated/model-capabilities.generated.json`(1,093,385 bytes, `generatedAt: 2026-07-29`) = **2758모델/183접두사**(1425 접두사형 + 1333 bare). 보조 `opengateway-models.json`(9프로바이더/60모델). 조회는 4단계 우선순위(runtime metadata → runtime snapshot → 번들 → 휴리스틱 패밀리). 유저 카탈로그는 Zod `OmoModelCatalogSchema`. **KDL 없음**(`find -name "*.kdl"` 0건 — 카탈로그는 JSONC+Zod).
- **fallback — 2개 독립 시스템**(`AGENTS.md`에 명시: "They operate independently"):
  1. **model-fallback(선제, `chat.params`)**: `hooks/model-fallback/next-fallback.ts`가 도달 불가·no-op을 건너뛰고 다음 rung 선택. 체인은 `model-core/src/agent-model-requirements.ts`(11 에이전트) + `category-model-requirements.ts`(8 카테고리)에 **하드코딩**. 기본 **off**(`pluginConfig.model_fallback ?? false`).
  2. **runtime-fallback(반응, `session.error`)**: `hooks/runtime-fallback/constants.ts` `DEFAULT_CONFIG = {enabled:false, retry_on_errors:[429,500,502,503,504], max_fallback_attempts:3, cooldown_seconds:60}` — **지수 백오프 없음**(시도 횟수+고정 쿨다운). 재시도 패턴 27개(`runtime-fallback-retryable-patterns.ts`, 중국어 6개 포함), 오버플로우 패턴 `context-overflow.ts`.
- **effort**: `model-core/src/reasoning-level.ts` — 7단계 `off|minimal|low|medium|high|xhigh|max` + `auto`, `clampReasoningLevel`는 사다리 안에서 **다운그레이드**, `:level` 접미사(`:max`는 실제 모델 ID와 충돌해 특수처리). `model-settings-compatibility.ts`가 family/metadata caps로 clamp하고 사유를 반환. 키워드 토글 `hooks/think-mode/` — 48개 다국어 키워드(ko/zh/ja/...) + 코드블록 제거.
- **컨텍스트**: `model-core/src/context-limit-resolver.ts` — `DEFAULT_ANTHROPIC_ACTUAL_LIMIT=200_000`, `ANTHROPIC_GA_1M_LIMIT=1_000_000`, `ANTHROPIC_1M_CONTEXT`/`VERTEX_ANTHROPIC_1M_CONTEXT` env, `hasGA1MContext()` 정규식. **선제 compaction** `hooks/preemptive-compaction-trigger.ts` `PREEMPTIVE_COMPACTION_THRESHOLD=0.78` + 60s 쿨다운, 실패 시 39파일 복구 사다리(`anthropic-context-window-limit-recovery/`).
- **cache**: **wire 수준 지시자 없음**(cache_control 검색 0건). `omo-senpi`의 `promptCache`는 로컬 메모리 블록 캐시일 뿐. 접두사 바이트 안정성 위생만 — 층위 차이(OpenCode의 AI SDK에 위임)이지 부족이 아님.
- **프로토콜**: 자체 wire 레이어 없음(OpenCode AI SDK 위 plugin). Copilot은 모델명 패턴으로 실제 프로바이더 역추정(`think-mode/switcher.ts`).
- **UX**: config-first. `model` 문자열이 카탈로그 키면 해당 엔트리로 전개(6단계 해석 파이프라인: UI override → user config → 카테고리 기본 → user fallback → 하드코딩 체인 → systemDefault). `model_profiles` 레인(Daily/Geeky × Normal/Heavy), `docs/guide/agent-model-matching.md`에 Recommended 순서 명시.

- **effort**: `packages/ai/src/types.ts` `ThinkingLevel = minimal|low|medium|high|xhigh|max`, `ModelThinkingLevel = off|...`. `models.ts` `getSupportedThinkingLevels()`/`clampThinkingLevel()` — `xhigh`/`max`는 `thinkingLevelMap`에 명시가 있을 때만. `/thinking` 슬래시 커맨드, `modelThinkingLevels["provider/modelId"]`로 모델별 기본값.

- **cache**: ① 캐시 인식 tool append — `supportsAdditionalTools`/`supportsToolSearch`로 도구를 mid-conversation system 메시지에 anchor된 `additional_tools` developer 항목이나 `tool_search_call/output` 쌍으로 넣어 **캐시된 프리픽스를 손대지 않음**(`api/openai-responses-shared.ts` `resolveTranscriptTools`/`appendSystemToolAdditions`). ② `cacheControlFormat:"anthropic"` → 시스템/마지막 도구/마지막 사용자 메시지에 `cache_control`(`api/anthropic-messages.ts` L1608 마지막 도구만). ③ `promptCacheKey` 64자 clamp(`api/openai-prompt-cache.ts`). ④ **cache warmer** `core/cache-warmer.ts`(453행): 60min/30min max age, 기대 절감 0.05 미만이면 스킵, TTL의 `min(0.9·ttl, ttl-10s)` 시점 리프레시, `PI_CACHE_RETENTION`.
- **프로토콜**: `KnownApi` 10종(`openai-completions`, `openai-responses`, `openai-codex-responses`, `anthropic-messages`, `bedrock-converse-stream`, `pi-messages` 등) + `Transport = sse|websocket|websocket-cached|auto`. `openai-codex-responses.ts`에 WebSocket→SSE 폴백 사다리. `api/` 46파일이 `X.ts` + `X.lazy.ts` 쌍, `lazyStream()`이 동기 반환 후 비동기 로드.

## oh-my-pi

## codex
- **카탈로그**: `codex-rs/models-manager/models.json` — 번들 `include_str!`, **정확히 11모델** 472KB. 필드: `context_window`(272000)/`max_context_window`(872000) 2단, `supported_reasoning_levels`, `default_reasoning_level`, `prefer_websockets`, `use_responses_lite`, `multi_agent_reasoning_effort`, 모델별 시스템 프롬프트(`model_messages.instructions_template`). 프로바이더는 `model-provider-info/src/lib.rs`에 **5개 하드코딩**(openai, amazon-bedrock(-runtime), ollama, lmstudio) + `config.toml` `model_providers` 맵(빌트인은 Bedrock만 부분 오버라이드 허용). 원격 `/models` 엔드포인트(ETag, 5s, 1MB cap), 캐시 TTL 300s + 절반 TTL 재검증, 실패 시 번들 카탈로그가 fallback. 알 수 없는 slug는 `model_info_from_slug()`가 272K fallback 메타데이터로 경고하며 대체.
- **fallback**: 재시도 = 지수 백오프 ±10% jitter(`codex-client/src/retry.rs`), 기본 request 4/stream 5회(hard cap 100), **`retry_429: false`**(429는 이 레이어에서 안 재시도). 오류별 allow/deny(`protocol/src/error.rs` `retry_delay()` — ContextWindowExceeded·Quota 등은 non-retryable). `responses_retry.rs`에 **WS→HTTPS 전송 폴백**(`try_switch_fallback_transport`, 재시도 소진 시). 모델 폴백은 compaction 한정(`compact_model_fallback.rs` `CompactionReason::ModelDownshift`, 텔레메트리 `codex.compaction.model_fallback`) + 번들 카탈로그 폴백.
- **effort**: `ReasoningEffort` **10종** — `None, Minimal, Low, Medium(기본), High, XHigh, Max, Ultra, Persistent, Custom(String)`(`protocol/src/openai_models.rs`). **모델이 광고하는 값**(`models.json`의 `supported_reasoning_levels`)으로 clamp. `ReasoningSummary` 4종, `Verbosity` 3종(Responses `text.verbosity`).
- **컨텍스트**: `auto_compact_token_limit()` = `context_window×9/10`을 config 값과 `min`. `effective_context_window_percent` 기본 95. scope `Total|BodyAfterPrefix`, `model_post_turn_compact_threshold_percent`(0~100). 유토큰 예산 compaction은 요약 없이 새 윈도만 설치(`compact_token_budget.rs`).
- **cache**: `prompt_cache_key`만 — 세션 id에서 파생(내부 서브에이전트는 `{source}:{parent_thread_id}`). `responses_request_properties_match()`가 **cache key 동등성을 연결 재사용 조건**으로 걸어둠(프리픽스가 바뀌면 연결을 안 재사용). Guardian 리뷰 세션은 key override로 사전 리뷰를 이어 붙임. **`cache_control`/브레이크포인트/TTL 없음**(전적으로 서버측 암묵 캐시).
- **프로토콜**: **Responses 전용** — `WireApi::Responses`가 유일 variant, `wire_api="chat"`는 역직렬화 에러. SSE(`POST /responses`) + 프로바이더 opt-in WebSocket(60분 제한) + realtime WebSocket 17파일. Azure base_url 마커 라우팅.
- **UX**: `codex -m`, `/model`(모델+노력 통합 팝업), `-c model="..."`, `debug models`. config keys `model`/`review_model`/`model_reasoning_effort`/`plan_mode_reasoning_effort`. 서브에이전트 `agents.default_subagent_model` + `default_subagent_reasoning_effort`(CLI > config).

## 관찰/시사점
1. **카탈로그 소재가 4갈래로 갈린다.** 원격 핀 + gitignore(pi-mono), 원격 + 번들 스냅샷(opencode, OmO), **KDL로 소스 오브 트루스를 쓰고 JSON으로 굽기**(oh-my-pi), 번들 JSON + 원격 ETag(codex). 반면 claude-code는 카탈로그 자체를 저장소에서 숨겨 두고 allow/deny만 노출한다 — "여러 프로바이더를 붙일 수 있는가"와 "단일 벤더 라인업을 제한할 것인가"라는 설계 목표 차이가 그대로 드러난다.
2. **fallback는 "재시도"와 "모델 전환"을 나눠야 읽힌다.** 재시도/backoff는 전원이 있으나(oh-my-openagent만 지수 백오프 없이 시도+쿨다운), **실패 시 다른 모델로 갈아타는 능력**은 oh-my-pi(`fallbackChains` role/wildcard/suffix), openclaw(primary+fallbacks, 16 reasons), hermes(27 reasons, 60s→4h 쿨다운), claude-code(3단 fallback + 같은 tier 하향), OmO(2중 독립 체인)에 집중돼 있다. opencode·pi-mono·codex에는 실질적 모델 폴백 체인이 없다.
3. **노력 사다리의 clamp 방향이 갈린다.** 대부분(oh-my-openagent, pi-mono, oh-my-pi, hermes)은 아래로 다운그레이드하고, openclaw는 **위로** 올린다. hermes는 "cost를 절대 올리지 않는다"를 명문으로, oh-my-pi는 KDL에 굽고 모델 ID 파싱을 금지한다(`model-thinking.ts` 헤더) — 런타임 재해석 vs 빌드타임 고정의 대비.
4. **프롬프트 캐시는 투자 강도가 두드러진다.** breakpoint 예산을 실제 관리하는 곳은 opencode(4 cap), oh-my-pi(工具1+系統1+殘餘 배분·volatile 경계), openclaw(마커 예산 엔진), hermes(4 기본 배치 + 회전 안정 key)다. claude-code는 TTL 정책·deferred tools·중간 시스템 블록·관측(`/cost` hit ratio)까지 **유지 규율의 서사**로 구현돼 있다. 반면 codex는 암묵 캐시 + `prompt_cache_key` 동등성으로 연결 재사용을 걸기만 하고, OmO는 아예 wire 레이어 위에 있어 캐시를 위임한다( capability gap이 아니라 layering 결과).
5. **선택 UX는 두 축으로 갈린다.** flat 목록 + 순환(opencode `/models`, pi-mono `/model`+scoped cycling) vs **role/agent 중심**(oh-my-pi 15 role + `@task`, OmO 6단계 파이프라인 + model_profile 레인, openclaw 에이전트별 primary/fallbacks, claude-code frontmatter alias 4값). 프론트마터에서 구체 모델 ID를 허용하는지(claude-code는 alias만, oh-my-pi는 `@role`, openclaw는 `primary+fallbacks`)가 확장성과 제약을 동시에 결정한다.
6. **스트리밍 프로토콜 채택은 명확히 갈린다.** codex는 Responses 전용(`chat`은 역직렬화 에러), claude-code는 Messages 전용(필드명으로 증명), opencode/pi-mono/openclaw는 다중 어댑터 + 선택 로직, oh-my-pi는 wire/server/schema 분해로 가장 큰 표면, hermes는 transport ABC로 플러그인 확장. 전송 폴백(WS→HTTPS)은 codex와 pi-mono만 가진다.
